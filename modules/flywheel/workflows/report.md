# 阶段性总结工作流

SessionStart hook 检测到报告缺失时触发。用于生成周报和月报。

## Step 0: 解析触发信号

hook 输出格式：

```
[FLYWHEEL] 以下工作报告尚未生成：
周报: records/_reports/2026-W23.md
月报: records/_reports/2026-05.md
请在本次会话中生成。
```

从信号中提取所有缺失报告的路径和类型（周报/月报）。对每个缺失的报告，按本工作流逐一生成。

## Step 1: 确定报告区间

**周报**：上周一至上周日。文件名格式 `{ISO年份}-W{两位周号}.md`（如 `2026-W23.md`）。

**月报**：上月 1 日至最后一日。文件名格式 `{年份}-{两位月份}.md`（如 `2026-05.md`）。

从文件名解析区间，不依赖当前日期推算——hook 信号中的文件名已是权威的区间表达。

## Step 2: 采集数据

### 2.1 筛选记录

读 `records/INDEX.md`，提取 `date` 落在报告区间内的所有记录行。记录行格式：

```
| {YYYY-MM-DD} | {slug} | {类型中文} | {合同/模板名} | {当事方} | {风险} | [详情](...) |
```

按日期排序。如区间内无记录，报告仅含概览段（"本月/本周无审查任务"）。

### 2.2 读取摘要

对筛选出的每条记录，读 `records/{date}-{slug}.md` 的正文首段（3-5 句摘要）。用于重点事项的叙事。

### 2.3 读取 clause 数据（如有）

对富记录，读 frontmatter 中的 clause 数组，用于风险聚焦统计。贫记录跳过此步。

### 2.4 读取对比基准

查找上一周期的报告文件：
- 周报：上周一的报告文件（如前一周的 W22）
- 月报：上月的报告文件

如存在，提取其中概览和任务分布段的数字用于对比。不存在则"对比上月/上周"段标注"首次报告，无对比数据"。

## Step 3: 生成报告

按以下结构写入 `records/_reports/{文件名}`：

```markdown
# 工作{周报/月报} — {日期范围}

## 一、概览

本期完成 {N} 项任务。{一句话定性总结——基于风险分布给出：}
- 高风险检出率明显上升 / 下降 / 持平
- 若有集中趋势，点出：集中出现在 {合同类型} 的 {条款维度}

## 二、任务分布

| 维度 | 分布 |
|------|------|
| 按类型 | {type1} {n1}, {type2} {n2}... |
| 按风险 | 高 {H} / 中 {M} / 低 {L} / 未评级 {U} |
| 按模式 | 简单 {S} / 复杂 {C}（仅当记录含 mode 字段时） |
| 统计区间 | {开始日期} 至 {结束日期} |

## 三、风险聚焦

{从 clause 数据统计本期风险最集中的 3-5 个条款维度。格式：}

- **{条款维度}**：{N} 次出现中高风险，{一句话说明}

{无 clause 数据时此节省略。}

## 四、重点事项

{从本期记录中选 2-5 条。选择标准：}
1. 高风险 → 一律写入
2. 首次出现的合同类型 → 写入
3. 首次出现的对手方 → 写入
4. 其余常规合同不写

每条格式：

### {合同名} — {日期}

{2-3 句话摘要，来自 records 正文。}

{如无满足标准的记录，写"本期无特别需要关注的事项。"}

## 五、对比上{周/月}

{从上一周期报告提取数字对比。如无上期报告：}

首次报告，无对比数据。

{如有上期报告，格式：}

- 总量：{N} 项（上期 {M} 项，{变化百分比}）
- 高风险占比：{X}%（上期 {Y}%，{变化方向}）
- 新增合同类型：{列出}（无则省略此行）
- 新增对手方：{列出}（无则省略此行）
```

## Step 4: 用户确认

报告生成后展示给用户：

```
{周报/月报}已生成。预览：

[展示完整报告内容]

是否确认写入 records/_reports/{文件名}？
回复"确认"写入，"修改 {具体内容}"调整后写入。
```

用户确认后写入文件。用户要求修改时，调整对应段落后重新展示确认。

## Step 5: 批量处理

如果 hook 信号同时包含周报和月报（如月初），逐份生成。每份独立确认写入，不批量操作。生成第一份 → 确认 → 写入 → 生成第二份 → 确认 → 写入。
