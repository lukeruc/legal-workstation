# Contract Analyze Skill（合同分析技能）

一个 [Claude Code](https://claude.ai/code) 技能，使用项目经理模式和专用子代理对法律合同进行全面的 AI 驱动分析。

## 概述

本技能可对 Markdown 格式的复杂法律合同进行深度的结构和文本分析。它模仿法律项目经理的工作流程：两个必选子代理执行首轮通读和交叉引用映射，然后项目经理（Claude）制定定制化分析策略，部署专业子代理，整合输出结果，最终交付一套结构化的可导航文档。

输出内容包括：当事方档案、术语定义词典、按主题分组的条款分析、交叉引用映射、冲突检测、质量验证等 —— 全部通过 Wiki 链接交叉引用，便于导航。

## 工作原理

```
┌─────────────────────────────────────────────────────┐
│                  Phase 1: 概览阶段                    │
│  ┌──────────────┐  ┌──────────────────┐             │
│  │ Overview     │  │ Reference Mapper │             │
│  │ Agent        │  │ Agent            │             │
│  └──────┬───────┘  └────────┬─────────┘             │
│         │ briefing.md       │ cross-ref-report.md    │
│         └────────┬──────────┘                       │
│                  ▼                                  │
│          Phase 2: 动态子代理部署                      │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐    │
│  │ Party    │ │ Clause   │ │ Terminology      │    │
│  │ Analyzer │ │ Grouper  │ │ Extractor        │    │
│  └──────────┘ └──────────┘ └──────────────────┘    │
│                  ▼                                  │
│          Phase 3: 结果整合                            │
│                  ▼                                  │
│          Phase 4: 结构化输出                           │
└─────────────────────────────────────────────────────┘
```

1. **Phase 1 — Overview Agent（概览代理）** 通读完整合同并生成结构化简报（合同身份、当事方概况、条款全景、显著特征）。**Reference Mapper（引用映射代理）** 追踪交叉引用、依赖链、潜在冲突和隐藏依赖。

2. **Phase 2 — 动态子代理** 根据简报揭示的内容动态创建。复杂合同可能生成 8–10 个专业代理；简单合同可能只需要 2–3 个。项目经理根据具体合同决定合适的代理组合。

3. **Phase 3 — 整合** 将所有子代理的输出合并为连贯的文档，确保术语一致、交叉引用已验证且质量检查到位。

4. **Phase 4 — 交付** 生成结构化的 `output/` 目录，包含索引、当事方档案、条款分析、术语定义和验证报告 —— 全部采用 Markdown 格式，通过 Wiki 链接导航。

## 使用方法

使用 Markdown 格式的合同文件调用技能：

```
/contract-analyze path/to/contract.md
```

**仅接受 Markdown（.md）文件。** 对于 PDF、DOCX 或扫描件，请先转换为 Markdown —— 注意保留标题层级和条款编号。

## 输出结构

```
sessions/{task-id}/
├── original/                   # 原始合同文件
└── output/
    ├── index.md                # 主概览与导航
    ├── structure.md            # 合同结构分析
    ├── parties/                # 当事方档案
    │   ├── _index.md
    │   └── {party-name}.md
    ├── definitions.md          # 术语定义词典
    ├── clauses/                # 按主题分组的条款分析
    │   ├── _index.md
    │   └── {topic}.md
    ├── validation-report.md    # 质量验证报告
    ├── open-questions.md       # 待澄清问题与歧义
    └── _internal/              # 项目经理工作文档
        ├── briefing.md
        └── cross-ref-report.md
```

## 质量标准

- **覆盖率**：超过 95% 的重要条款在输出中得到处理
- **准确性**：条款引用、金额、日期和当事方名称经过验证
- **一致性**：所有文档中术语使用保持一致
- **可追溯性**：每个分析结论都引用了来源条款
